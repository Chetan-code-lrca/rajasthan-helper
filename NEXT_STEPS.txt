🎯 TROUBLESHOOTING
════════════════════════════════════════════════════════════════════════════════

If you get an error:

"python: command not found"
  → Use: python3 FIX_CLI.py

"ModuleNotFoundError after fix"
  → Run: pip install -e . again

"pip not found"
  → Make sure Python is installed: python --version

"Command 'rajasthan-helper' not found after pip install"
  → Restart your terminal
  → Or use: python -m rajasthan_helper weather Jaipur

"Weather API timeout"
  → Normal - API is sometimes slow
  → Try again: rajasthan-helper weather Jaipur
