📋 COMMANDS PROVIDED
═════════════════════════════════════════════════════════════════════════════

WEATHER COMMAND
  $ rajasthan-helper weather [city]
  - Default: Jaipur
  - Fetches real-time weather from wttr.in API
  - Shows: Temperature, Condition, Feels Like, Humidity
  - Rich table with cyan border and colors

FESTIVAL COMMAND
  $ rajasthan-helper festival [month]
  - Shows all festivals if no month specified
  - 5 Rajasthan festivals available:
    * January: Makar Sankranti 🪁
    * March: Holi 🎨
    * October: Diwali 🪔
    * November: Pushkar Camel Fair 🐪
    * December: Winter Festivals ❄️
  - Rich panel output with emojis

TRAVEL TIPS COMMAND
  $ rajasthan-helper tip [city]
  - Default: Jaipur
  - 5 Cities with 3 curated tips each:
    * Jaipur 🏰 (Amber Fort, Bazaars, Food)
    * Udaipur 🚤 (Lake, Palace, Street food)
    * Mumbai 🥔 (Vada pav, Gateway, Markets)
    * Jodhpur 🏛️ (Fort, Blue city, Spices)
    * Pushkar 🕌 (Camel Fair, Lake, Temples)
  - Rich table with green border
