## 💡 Key Design Decisions Explained

### 1. **3-Second API Timeout**
- **Why**: Real-world balance
- **Not 5s**: Too long, users feel app is frozen
- **Not 1s**: Too short, fails on slower connections
- **3s**: Empirically tested for India's typical internet speeds

### 2. **Fallback Weather Data**
- **Why**: Real users have unreliable connections
- **What happens**: If API is slow/down, show cached data + warning
- **Benefit**: App stays useful even when internet fails
- **Alternative approach**: Many apps just crash (bad UX)

### 3. **12 Months of Festivals**
- **Why**: Educational value
- **Benefit**: Users learn about cultures throughout the year
- **Not just tourist seasons**: Respects all Indian traditions

### 4. **Case-Insensitive Input**
- **Why**: User-friendly
- **Benefit**: Users don't need to remember capitalization
- **Implementation**: Normalize input internally

### 5. **Rich Formatting with Emojis**
- **Why**: Visual appeal + clarity
- **Benefit**: Terminal output looks professional and fun
- **Accessibility**: Emojis help scan information quickly
