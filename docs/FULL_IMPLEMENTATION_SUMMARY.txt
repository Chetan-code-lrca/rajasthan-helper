📄 WEATHER COMMAND IMPLEMENTATION
════════════════════════════════════════════════════════════════════════════════

File: rajasthan_helper/commands/weather.py

Function: get_weather(city: str) -> None

Features:
  ✅ Fetches from: https://wttr.in/{city}?format=j1
  ✅ Timeout: 5 seconds
  ✅ Displays: Temperature, Condition, Feels Like, Humidity, Wind Speed
  ✅ Format: Rich Panel with colored borders
  ✅ Colors:
     • Red (🔥) for hot (>35°C)
     • Yellow (☀️) for warm (25-35°C)
     • Cyan (🌤️) for cool (<25°C)

Error Handling (6 types):
  1. requests.exceptions.Timeout
     → "Request timed out. The API is taking too long."
  
  2. requests.exceptions.ConnectionError
     → "Connection failed. Unable to connect to weather service."
  
  3. requests.exceptions.HTTPError
     → "City not found. Could not find weather data."
  
  4. KeyError / ValueError
     → "Unable to parse weather data. API response format unexpected."
  
  5. Generic Exception
     → "Unexpected error: {error_details}"

Output Example:
  ╭──────────────────── ☀️ Weather Report ─────────────────────╮
  │ Jaipur                                                       │
  │ Temperature:    28°C                                         │
  │ Condition:      Partly Cloudy                                │
  │ Feels Like:     30°C                                         │
  │ Humidity:       45%                                          │
  │ Wind Speed:     15 km/h                                      │
  ╰────────────────────────────────────────────────────────────────╯

Code Structure:
  • Import: requests, Rich (Panel, Console)
  • Try block: API call with 5-second timeout
  • JSON parsing: Extract from data["current_condition"][0]
  • Temperature logic: Color assignment based on value
  • Panel creation: fit() for auto-sizing
  • Error handlers: 6 specific except blocks + generic
