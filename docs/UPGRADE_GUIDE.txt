💡 USAGE EXAMPLES
────────────────────────────────────────────────────────────────────────────────

Get live weather (or fallback if slow):
  rajasthan-helper weather Jaipur

Get all 7 festivals in a table:
  rajasthan-helper festival

Get a specific festival:
  rajasthan-helper festival March

Check if there's a festival in a month:
  rajasthan-helper festival May

Get travel tips for a city:
  rajasthan-helper tip Jaisalmer

See version info:
  rajasthan-helper --version
