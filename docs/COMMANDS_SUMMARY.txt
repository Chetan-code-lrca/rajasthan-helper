📊 COMMAND SUMMARY
─────────────────────────────────────────────────────────────────────────────────

WEATHER:
  Input:  rajasthan-helper weather Jaipur
  Output: Rich panel with current weather
  Color:  Temperature-coded (hot=red, warm=yellow, cool=cyan)
  Fields: Temp°C, Condition, Feels Like, Humidity%, Wind Speed km/h
  Error:  Friendly message if city not found

FESTIVAL:
  Input:  rajasthan-helper festival               (show all)
  Input:  rajasthan-helper festival March         (show specific)
  Output: Magenta table (all) or Yellow panel (one)
  Data:   5 festivals with names & descriptions
  Error:  Shows available months if invalid

TIPS:
  Input:  rajasthan-helper tip Udaipur
  Output: Green panel with emoji-prefixed tips
  Data:   5 cities with 3-4 tips each
  Error:  Shows available cities if invalid
