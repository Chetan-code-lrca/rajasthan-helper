✅ Weather Command
   Function: get_weather(city)
   Source: requests.get('https://wttr.in/{city}?format=j1')
   Output: Rich panel with temperature-colored borders
   Shows: Temp°C, Condition, Feels Like, Humidity%, Wind Speed km/h
   Colors: Red (hot >35°C), Yellow (warm 25-35°C), Cyan (cool <25°C)
   Emojis: 🔥☀️🌤️🌦️ based on temperature
   Error handling: Timeout, ConnectionError, HTTPError, JSON errors
   Usage: rajasthan-helper weather Jaipur

✅ Festival Command
   Function: show_festival(month)
   Data: 5 hardcoded Rajasthan festivals
   
   January   → Makar Sankranti 🪁 (Kite flying festival)
   March     → Holi 🎨 (Festival of colors & joy)
   October   → Diwali 🪔 (Festival of lights & sweets)
   November  → Pushkar Camel Fair 🐪 (Sacred camel trading)
   December  → Winter Festivals ❄️ (Music & dance)
   
   Show all: Rich magenta-bordered table
   Show one: Rich yellow-bordered panel
   Error: Shows available months if invalid
   Usage: rajasthan-helper festival March

🔧 ERROR HANDLING IMPLEMENTATION
════════════════════════════════════════════════════════════════════════════════

WEATHER ERRORS:
  1. requests.exceptions.Timeout
     → Message: "Request timed out. The API is taking too long."
  
  2. requests.exceptions.ConnectionError
     → Message: "Connection failed. Unable to connect to weather service."
  
  3. requests.exceptions.HTTPError
     → Message: "City not found. Could not find weather data."
  
  4. KeyError / ValueError
     → Message: "Unable to parse weather data. API response format unexpected."
  
  5. Generic Exception
     → Message: "Unexpected error: {error_details}"

FESTIVAL ERRORS:
  1. Invalid month (not in FESTIVALS dict)
     → Message: "Error: Month '{month}' not found"
     → Shows: "Available months: January, March, October, November, December"
  
  2. Generic Exception
     → Message: "Unexpected error: {error_details}"

TIP ERRORS:
  1. Invalid city (not in TIPS dict)
     → Message: "Error: City '{city}' not found"
     → Shows: "Available cities: Jaipur, Udaipur, Mumbai, Jodhpur, Pushkar"
  
  2. Generic Exception
     → Message: "Unexpected error: {error_details}"
